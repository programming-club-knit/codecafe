## Description
The hero call-to-action has white text on a pale yellow background, which is almost invisible. It also gives no visual feedback on hover or keyboard focus.

## Acceptance criteria
- [ ] Text/background contrast is at least **4.5:1** (WCAG AA) in light **and** dark theme
- [ ] Visible `:hover` style
- [ ] Visible `:focus-visible` outline
- [ ] Don't change the button's size or the yellow brand colour

## Tip
Use the browser DevTools contrast checker.
