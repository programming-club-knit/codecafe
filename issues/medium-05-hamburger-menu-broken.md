## Description
On screens narrower than 700px the hamburger button does nothing, so phone users can't navigate.

## Acceptance criteria
- [ ] Button opens and closes the nav on mobile
- [ ] Menu closes after a link is clicked
- [ ] Menu closes with the `Escape` key
- [ ] `aria-expanded` is kept in sync on the button
- [ ] Resizing the window back to desktop leaves the nav in a sane state
- [ ] Works on all four pages

## Files
`js/main.js`, `css/style.css`
